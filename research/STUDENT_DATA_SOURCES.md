# Student data sources for SCR-1 (student-voice test corpus)

Researcher notes, 24 Oct 2026. These sources ground `tests/fixtures/students/*.json` and
`research/STUDENT_SCRIPTS.md`. **We used them for patterns only.** Nothing was downloaded in bulk, no real
student utterance is copied into a fixture, and no personal information is included. Every fixture line is
original, written in the style the sources describe. Where a source restricts redistribution (CoMTA, NCTE,
Kaggle), we read only the paper, README or label names, not the data itself.

## Patterns used to write the cards

**Talk (how turns look)**
- Most turns are a bare claim: a number, "its half", "no". A reason appears only when something concrete pulls it out (TalkMoves 2.3:1 claims to reasons; NCTE about 4 words per turn).
- Tentative endings: "12?", "i think", "is that right??" (Bridge). Self-repair mid-turn: "6 times 4, wait no, over 2" (NCTE).
- Kids slide back to a wrong answer after accepting a fix (MathDial). Cards with a misconception state it again under pressure.
- Wrong but confident: "u times all the sides" (Eedi / Barton).
- Answer-seeking when the tutor withholds: "just tell me", "google it" (CoMTA setting).
- Texting layer, our inference (no dataset covers kids' texting style): lowercase, few or no apostrophes ("its", "dont"), "u/ur/bc/idk/wdym/rn", "x" or "*" for times, "/2" for half, double texts, rare 😭/💀, light slang only (TRENDS_BRAINROT.md: heavy brainrot reads as 2025 and cringe).

**Misconceptions (triangle area)**: forget the ½ (agree with Pip's 24) · slant side as height · multiply every number / all three sides · add the sides (perimeter) · height must be a side (stuck on leaning or obtuse ones) · right triangles only · "half because triangles are half" with no reason · obtuse height outside (handled correctly by one persona, as a curveball for Pip).

**Curiosity moves (from IM, MathDial "probing", TalkMoves "revoicing", Bridge experts)**: notice and wonder before computing · perturb the question (new numbers, skinny triangle, leaning triangle) · predict, then check · build up from the rectangle the student already knows · "does it work on another triangle? is there one where it doesn't?" · revoice in the kid's own words · work from the student's own numbers, not new textbook ones.

## Not used / caveats
- MathDial students are LLM-simulated and noticeably more cooperative and articulate than real kids, so we used them for the teacher-move taxonomy and the "slides back" behavior, not for voice.
- NCTE is classroom speech, not texting, and grades 4–5. Bridge is grades 1–5. Our users are 10–15, so the texting style is extrapolated (marked above as inference).
- The CoMTA and NCTE data themselves were not opened (license / gated access).
